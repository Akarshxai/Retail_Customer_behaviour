# 🛍️ Retail Customer Behavior & Data Analysis

An end-to-end data analytics project focused on cleaning retail transaction data, performing exploratory SQL analysis to unearth customer trends, and visualizing key business metrics through an interactive Power BI dashboard.

---

## 📌 Project Overview

Understanding customer purchasing behavior is critical for retail optimization, inventory management, and targeted marketing strategies. This repository demonstrates a complete data workflow:
1. **Data Preprocessing & Cleaning**: Raw dataset transformation using Python in Jupyter Notebook.
2. **Database Integration & SQL Insights**: Querying transformed data using MySQL to extract actionable customer behavior metrics.
3. **Interactive Dashboard**: Visualizing KPI trends and customer segments using Power BI.

---

## 🛠️ Tech Stack & Tools

- **Data Processing**: Python (`pandas`, `numpy`), Jupyter Notebook
- **Database Querying**: MySQL
- **Visualization**: Microsoft Power BI
- **Version Control**: Git & GitHub
